# Godot-2D-platformer-template
This is a advanced 2d platformer template for Godot Engine with advanced movement mechanics and camera controls.

# Features
## Running

- Acceleration
- Max speed
- Deceleration
- Turn speed

## Camera

- Zoom
- Lookahead
- Damping
- Ignore jumps

## Jumping

- Max height
- Down gravity
- Jump duration
- Air acceleration
- Air control
- Air brake
- Double jump
- Variable height

## Assists

- Coyote time
- Jump buffer
- Terminal velocity

# Getting started

## Prerequisites
- Godot Engine 4.x or later

##Installation

1. Clone the repository:
	```git clone https://github.com/RicoLViviers/Godot-2D-platformer-template.git```
2. Open the project in Godot
3. Explore the demo scenes and customize project to your liking
